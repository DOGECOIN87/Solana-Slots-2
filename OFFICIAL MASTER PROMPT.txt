📜 OFFICIAL MASTER PROMPT — Q2 2025 (Rev‑D, UI/UX + Perf edition)

Copy‑paste this entire file into your AI‑coding assistant (e.g. VS Code Cline ⇧⌘K) after you cd into a fresh repo.   It scaffolds, documents, tests, designs, containerises and continuously self‑improves your project while obeying strict guard‑rails.

0 PURPOSE & SCOPE

Build a production‑grade front‑, back‑ or full‑stack web‑app using a multi‑agent tool‑chain (Context7 ▷ Research ▷ Figma ▷ Code‑Review) plus automated CI/CD, testing, docs, containers, security scanning and pixel‑perfect, performant UI/UX design.   Works out‑of‑the‑box on any dev box or CI runner.

0‑A 🚦 GOLDEN RULES (v6)

Markdown is source‑of‑truth — keep README.md, PLANNING.md, TASK.md, CHANGELOG.md current.

≤ 500 LOC per file — when a file approaches the limit refactor into modules.

One task per message — atomic prompts → consistent output.

Restart chats early — long threads degrade answers; summarise → reopen.

Test early, test often — each new function/class mandates unit tests.

Be specific — concrete examples + constraints beat abstractions.

Document as you code — inline comments, docstrings, ADRs.

Guard secrets — never hard‑code; use .env / cloud KMS; git add -n before commit.

Performance budgets — Lighthouse ≥ 90 & JS bundle ≤ 250 kB; fail CI if breached.

0‑B 🧑‍💻 Prompt Hygiene (assistant must enforce)

On follow‑up requests reject or re‑scope if user bundles > 1 unrelated change.

If context is missing attempt, in order: use context7 → ask research: → use figma → ask code‑review: → ask human.

11 CI/CD (GitHub Actions)

name: CI
on: [push, pull_request]

jobs:
  build:
    runs-on: ubuntu-latest
    permissions: { contents: read, security-events: write }
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 18, cache: pnpm }
      - run: corepack enable && pnpm install --frozen-lockfile
      - run: pnpm run lint && pnpm run test -- --coverage
      - run: pnpm run a11y
      - run: pnpm run lhci
      - uses: codecov/codecov-action@v4
      - name: Upload SBOM/scan
        uses: github/codeql-action/init@v3
        with: { languages: javascript }
      - uses: github/codeql-action/analyze@v3

  release:
    if: github.ref == 'refs/heads/main' && github.event_name == 'push'
    needs: build
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 18 }
      - run: corepack enable && pnpm install --production=false
      - run: pnpm run release
