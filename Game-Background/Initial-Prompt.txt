
Build a **provably-fair** 5×3 slots game on the Solana blockchain.  
The assistant must scaffold, document, test, design, containerise, and continuously self-improve the project while obeying the guard-rails below.

---

## 0 PURPOSE & SCOPE  
* Deliver a production-grade web dApp (“Solana Slots”) that:  
  1. Shows a responsive 5×3 slot-machine UI.  
  2. Uses **Switchboard v3 VRF** for random, verifiable spins.  
  3. Records wagers, payouts, and VRF proofs on-chain.  
  4. Pays winners in SOL (testnet by default).  
  5. Ships with CI/CD, Storybook, a11y, Lighthouse, and security scanning.

    All spin results come from on-chain VRF callback.

6 VRF INTEGRATION (STEP SUMMARY)

    Create a programAuthority PDA inside the Anchor program.

    Instantiate a Switchboard VRF account with that PDA as authority, and set a callback to consume_randomness.

    Expose request_spin instruction:

        verifies wager, requests VRF.

    Callback consume_randomness:

        derives final reel indexes, stores outcome, emits SpinResult event.

    Front-end listener subscribes to SpinResult and animates reels.

    Provide a Script (scripts/init-vrf.ts) to fund and create VRF accounts on devnet/testnet.
    Web3 Infrastructure for Everyone
